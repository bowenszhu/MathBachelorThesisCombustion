\chapter{Julia programming language} \label{ch:julia}

Julia is a high-level, high-performance, dynamic programming language designed by \textcite{julia}. Many of its features are well suited for numerical and scientific computing. It is claimed that Julia can achieve machine performance without sacrificing human convenience, namely the so-called \texttt{Walks like Python, Runs like C}. The recent development of a large number of Julia packages including various mathematical libraries, data manipulation tools and packages for general purpose computing enrich the Julia ecosystem for community use. In our situation, we would like to attempt applying Julia to model pollutant formation using the chemical reaction network approach.
