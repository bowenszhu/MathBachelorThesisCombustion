\chapter{Julia programming language} \label{ch:julia}

Julia is a high-level, high-performance, dynamic programming language designed by \textcite{julia}. Many of its features are well suited for numerical and scientific computing. It is claimed that Julia can achieve machine performance without sacrificing human convenience, namely the so-called \texttt{Walks like Python, Runs like C}. The recent development of a large number of Julia packages including various mathematical libraries, data manipulation tools and packages for general purpose computing enrich the Julia ecosystem for community use. In our situation, we would like to attempt applying Julia to model pollutant formation using the chemical reaction network approach. The following sections introduce the main relevant packages and how they contribute to this project.

\section{DifferentialEquations.jl}

DifferentialEquations.jl \parencite{DifferentialEquations.jl} is a suite for numerically solving differential equations. It assists convenient ODE construction and works well together with Plots.jl to visualize solutions. One of the key features is that it has many built-in solver algorithms which supports diverse types of differential equations in different scales.

\section{ModelingToolkit.jl}

ModelingToolkit.jl \parencite{ModelingToolkit.jl} is a modeling language for high-performance symbolic-numeric computation in scientific computing. It allows for users to give a high-level description of a model for symbolic preprocessing to analyze and enhance the model. It is compatible with DifferentialEquations.jl as all the symbolic systems have a direct conversion to a numerical system which can then be handled through the SciML interfaces. ModelingToolkit.jl can be used to symbolicify numerical code and do symbolic calculation. More specifically, it is capable to automatically derive the Jacobian function of an \texttt{ODEProblem}.

\section{LightGraphs.jl and SimpleWeightedGraphs.jl}

To simulate the reaction network, special tools and data structures are needed to store and process graphs. LightGraphs.jl and SimpleWeightedGraphs.jl \parencite{LightGraphs} offer a set of simple and graph implementations which make it easy for us to define arbitrary complex networks. Besides constructing directed, weighted networks by adjacency matrices, many built-in graph structures are available, such as \texttt{barabasi\_albert} for the Barab\'{a}si–Albert model.
