\chapter{Chemical reaction network with Julia} \label{ch:network}

This chapter presents solving reaction networks with Julia. It starts from the formal mathematical model. Application on 5-node 5-edge networks is illustrated. At the end, the performance of solving large networks with various solver algorithms are evaluated and compared. 

\section{Mathematical model}

As briefly introduced in section~\ref{sec:CRN}, an internal combustor space is modelled as a network of graph $G$ with $n$ vertices $V$ and some edges $E$. A vertex $v$ is a container with chemical reactions perfectly stirred which only involve chemistry. An edge $e$ is a pipe serving as a channel for flowing species with prescribed velocity which captures transport.

Each vertex $v_i$ contains $s$ chemical species. Edge $e_{i,j}$ connects vertex $v_i$ and vertex $v_j$. $\mathbf u(t)$ is a vector of unknown species concentration.

\begin{align}
    \mathbf u(t) &= 
    \begin{pmatrix}
        \mathbf u_1(t) \\
        \vdots \\
        \mathbf u_i(t) \\
        \vdots \\
        \mathbf u_n(t)
    \end{pmatrix} \\
    \mathbf u_i(t) &=
    \begin{pmatrix}
        u_{i,1}(t) \\
        \vdots \\
        u_{i,j}(t) \\
        \vdots \\
        u_{i,s}(t)
    \end{pmatrix}
\end{align}
where $\mathbf u_i(t)$ is a subvector corresponding to vertex $v_i$. $u_{i,j}$ denotes the concentration of the $j$-th species in vertex $v_i$.

The dynamics of the entire system is modelled by a set of ordinary differential equations (ODEs)
\begin{equation}
    \frac{\mathrm d \mathbf u (t)}{\mathrm d t} = \mathbf F ( \mathbf u (t), t) =  \mathbf F_{\mathrm{chemistry}} ( \mathbf u (t), t) + \mathbf F_{\mathrm{transport}} ( \mathbf u (t), t)
\end{equation}
with prescribed initial conditions
\begin{equation}
    \mathbf u(t = 0) = \mathbf u_0.
\end{equation}

The aim is to solve the large-scale ODE system with sufficient accuracy for a certain time range. The differential equations are stiff as it involves fast chemistry and slow transport, for which we will apply implicit time integration methods with variable time steps.

\section{5-node-5-edge networks} \label{sec:5network}

In this section, we apply Julia to solve networks consisting of 5 nodes and 5 edges in two different connectivity configurations. The code can be found in appendix~\ref{app:5network} on page~\pageref{app:5network}. Each vertex in the graph is a node with the one-step reaction mechanism~\eqref{re:one-step} of methane combustion as its internal chemistry. The ODE system is defined as follows, $\forall i \in \{1,2,3,4,5\}$,
\begin{equation}
    \frac{\mathrm d \mathbf u_i(t)}{\mathrm d t} = \frac{\mathrm d}{\mathrm d t}
    \begin{pmatrix}
        u_{i,1} \\
        u_{i,2} \\
        u_{i,3} \\
        u_{i,4}
    \end{pmatrix}
    % = \frac{\mathrm d}{\mathrm d t}
    % \begin{pmatrix}
    %     [\ce{CH4}]_i \\
    %     [\ce{O2}]_i \\
    %     [\ce{CO2}]_i \\
    %     [\ce{H2O}]_i
    % \end{pmatrix}
    % = k [\ce{CH4}]_i^{n_{\ce{CH4}}} [\ce{O2}]_i^{n_{\ce{O2}}}
    % \begin{pmatrix}
    %     -1 \\
    %     -2 \\
    %     1 \\
    %     2
    % \end{pmatrix}
    = k u_{i,1}^{n_{\ce{CH4}}} u_{i,2}^{n_{\ce{O2}}}
    \begin{pmatrix}
        -1 \\
        -2 \\
        1 \\
        2
    \end{pmatrix}
    + \sigma \sum_{j=1}^5 G_{ji} (\mathbf u_j - \mathbf u_i)
\end{equation}
where $u_{i,1}$, $u_{i,2}$, $u_{i,3}$, $u_{i,4}$ denote the concentration of \ce{CH4}, \ce{O2}, \ce{CO2} and \ce{H2O} in the $i$-th vertex respectively. The rate coefficient $k = A T^\beta \exp(- E_a / R T)$, the reaction orders $n_{\ce{CH4}}$ and $n_{\ce{O2}}$ are the same with the values in table~\ref{tab:one-step} on page~\pageref{tab:one-step}. The graph structure and the flow rate are captured by the parameters $\sigma$ and $G_{ji}$.

Moreover, as for the initial condition, there are fuels in the first node and none in other nodes at the start time. That is, methane is injected into node 1 only at the outset and flow travels downstream to other nodes. Node~1 acts as an inlet for \ce{CH4}. The initial values of \ce{O2} in nodes 1, 3, 5 are set to zero.

\section{Performance}

We solved the one- and the two-step reaction mechanism of methane combustion with the default solver algorithm\footnote{Julia DifferentialEquations.jl automatically chooses an efficient method for the input problem.} and applied the 5th order A-stable stiffly stable Rosenbrock method \texttt{Rodas5} to solve the 5-node-5-edge networks. So far only small (<50 ODEs) problems are examined. However, in order to utilize Julia on real combustion simulation, we shall test its capability on solving large reaction networks with more species beforehand.

Besides \texttt{Rodas5}, we consider the second order A-B-L-S-stable one-step ESDIRK method \texttt{TRBDF2} which is suggested by DifferentialEquations.jl documentation for slightly larger problems (with <2000 ODEs). Furthermore, it is possible to optimize the linear solvers for certain differential equation integration methods. We also evaluate the performance of \texttt{TRBDF2} in combination with the GMRES linear solver.

For simplicity, we employ the test network shown in figure~\ref{fig:test-network}. All nodes reside in the same line with a directed edge connecting every pair of consecutive nodes. The internal chemistry in each node is the one-step mechanism of methane combustion. The initial values are gradually decreasing from node 1 to node n, although this does not really affect the execution time. The parameters are kept the same as the 5-node-5-edge networks discussed in section~\ref{sec:5network}.
